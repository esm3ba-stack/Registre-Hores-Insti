# Registre d'hores de l'insti

Web personal per portar el registre de faltes i retards per projecte (curs 2026-27).

- Cada projecte permet faltar el **15%** de les seves hores.
- Cada **retard** suma **⅓ h** de falta al seu projecte.
- Inclou **IPO II** (Itinerari per a l'Ocupabilitat II): 2 h cada dimecres lectiu, a més de les 3 h del projecte.
- Les dades es guarden al navegador (`localStorage`). Fes servir *Copiar còpia* per guardar-les o passar-les a un altre dispositiu.

Tot és dins d'`index.html` (estils, temporització i lògica).

Basat en [App-Faltes](https://github.com/lluc1996/App-Faltes) de lluc1996.

## Publicar a GitHub Pages

1. GitHub → **Settings** → **Pages**.
2. *Source*: **Deploy from a branch**.
3. *Branch*: `main`, carpeta `/ (root)` → **Save**.
4. En 1-2 minuts la web és a `https://esm3ba-stack.github.io/Registre-Hores-Insti/`.
